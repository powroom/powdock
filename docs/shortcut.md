# Shortcuts

Every keyboard shortcut in pow/dock. `Mod` means `Ctrl` on Windows and Linux, or `⌘` on macOS. Press `?` in the app to see them in a dialog.

## General

| Shortcut  | What it does                      |
| --------- | --------------------------------- |
| `Mod + K` | Open or close the command palette |
| `Mod + B` | Show or hide the sidebar          |
| `?`       | Show the keyboard shortcuts       |

## Lists

These work on the Containers, Images, Volumes and Networks pages.

| Shortcut | What it does                 |
| -------- | ---------------------------- |
| `/`      | Move focus to the search box |

## Terminal

| Shortcut           | What it does                                  |
| ------------------ | --------------------------------------------- |
| `Ctrl + Shift + V` | Paste into the terminal (select text to copy) |

`Mod + K`, `?` and `/` do not run while the terminal has focus, because the terminal takes the keys. `?` and `/` also do nothing while you type in a text field.
